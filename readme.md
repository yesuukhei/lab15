# Lab14 - Java Maven Project

## 🧾 Төслийн тухай

Энэ бол Java + Maven төслийн үндсэн жишээ бөгөөд дараах нэмэлтүүдийг ашигласан:

- JUnit 5 (тест)
- Surefire Plugin (тест ажиллуулах)
- Checkstyle (кодын стандарт шалгах)
- JaCoCo (coverage шалгах)

## 🛠️ Хэрхэн ажиллуулах вэ?

```bash
# Тест ажиллуулах
mvn test

# Кодын загвар шалгах
mvn checkstyle:check

# Coverage тайлан гаргах
mvn jacoco:report
```
